How to read it

  • Each screen is a real page or email from the site, running on a test database. The people are made up.
  • Time runs left to right. An arrow's label is the button or link that leads to the next screen.
  • The host is on a laptop. Guests are on a phone, since most open an invitation from an email or a text.
  • Long pages are cropped to the part the step is about. Select a screen to see the whole page.

      How it was made

      A Playwright script walks the flow the way the end-to-end tests do and saves each step. Run it again after a change and the map shows the new pages.

      npx playwright test --config e2e/flows/playwright.config.ts
